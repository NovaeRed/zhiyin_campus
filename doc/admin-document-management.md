## 接口契约

`GET /admin/documents/{id}/original` 返回原始文件字节，`?download=true` 返回附件响应。每次验证当前存活账号及文档管理权限，学生403、未认证401、文件缺失或越出知识存储目录404。实际文件路径通过规范化和真实路径检查，不能借数据库异常路径下载项目配置。响应包含原文类型、UTF-8文件名、`no-store`、`nosniff` 与隔离策略，支持PDF字节范围请求。HTML预览禁用脚本、表单及外部资源。

`PUT /admin/documents/{id}` 保留旧的标题/版本编辑，同时支持可选的完整 `metadata` 对象：

```json
{
  "title": "培养方案",
  "version": "v1",
  "metadata": {
    "targetMajor": "数学与应用数学",
    "targetGrade": 2024,
    "targetCohort": "2028届",
    "department": "教务处",
    "effectiveDate": "2024-09-01"
  }
}
```

省略 `metadata` 保留当前适用范围；提供该对象即替换以上五项，可用null清空。毕业届别独立于入学年份，日期校验真实日历。只允许编辑已完成入库的启用或停用文档。

在同一事务中锁定文档并更新标题、版本、文档元数据、全部父子切片的 `target_major/target_grade` 列及对应元数据，审计记录原属性与新值。文件名、解析信息和其他元数据保留；不改写原始文件、切片正文、父子关系或Embedding，不调用重新向量化。空值使用显式JSON节点保存，避免应用全局NON_NULL设置省略清空值。属性修正影响后续检索，不能将属性编辑视为原文事实修改或版本重建。
